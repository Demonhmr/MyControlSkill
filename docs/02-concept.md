# Концепция приложения

## Позиционирование

Не «конструктор идеального руководителя», а **диагностика восприятия + навигатор по своей уникальной комбинации силы**. Ядро ценности — три вещи, которые обычные ассессменты не делают:

1. Явно ищет и приоритизирует **деструкторы** (что тушить в первую очередь)
2. Явно **запрещает/обесценивает** инвестиции в подтягивание середины (15–70 перцентиль)
3. Считает **компетенции-спутники** и подбирает «точку роста» по трём фильтрам (сила × интерес × потребность), а не выдаёт универсальный чек-лист

Рабочая логика: **«Деструктор → Суперсила → Спутники»**.

## Пользователи и роли

- **Руководитель (субъект оценки)** — проходит самооценку, инициирует 360°, получает рекомендации
- **Респонденты 360°** (подчинённые, коллеги, вышестоящий руководитель) — дают оценку и качественную обратную связь
- **HR/L&D** — видит агрегаты по орг. единице, приоритизирует деструкторы как риск, а не как повод «отправить на курс»
- (опционально) **Коуч/ментор** — получает профиль для сессии развития

## Основные модули

1. **Профиль компетенций** — 19 компетенций + 10 деструкторов как отдельная ось
2. **Сбор данных**: самооценка + 360° (количественные шкалы + 2 «правильных» открытых вопроса)
3. **Движок скоринга**: перцентильная нормализация относительно нормативной базы, а не абсолютные баллы
4. **Карта «Сила–Интерес–Потребность»** — интерактивный выбор точек роста
5. **Рекомендательный движок**: матрица компетенций-спутников + библиотека «трудных диалогов»
6. **Трекер прогресса**: повторные пульс-опросы по выбранной связке
7. **HR-дашборд**: агрегированная карта деструкторов и суперсил по команде/оргструктуре

## Система оценки

### Единица измерения — перцентиль, не балл

Скоринг относительный (перцентиль относительно нормативной базы: роль/грейд/индустрия), так как вся логика (75-й, 90-й, 10-й перцентили) требует сравнительной шкалы.

Зоны по каждой из 19 компетенций:
- **< 10 перцентиль → Деструктор** (приоритет №1)
- **10–70 перцентиль → Норма/не приоритет**
- **70–90 перцентиль → Сильная сторона-кандидат**
- **≥ 90 перцентиль → Суперсила**

### Источники данных

| Источник | Что даёт | Вес |
|---|---|---|
| Самооценка | стартовая гипотеза, систематически завышена | низкий, только для delta (слепые зоны) |
| 360° количественный | перцентильный профиль | основной |
| 360° качественный (2 открытых вопроса) | поведенческие примеры | обогащающий |
| Бизнес-метрики команды (опционально) | верификация связки «лидерство → результат» | валидирующий |

### Алгоритм обработки (приоритеты)

```
Шаг 1: DESTRUCTOR SCAN
  если перцентиль деструктора < 10 → приоритет = MAX
  блокирует показ "точек роста" до проработки

Шаг 2: STRENGTH SCAN
  компетенции с перцентилем >= 70 → кандидаты в "точки роста"

Шаг 3: BLIND SPOT CHECK
  delta = |самооценка - 360°|; большая delta → флаг "слепая зона"

Шаг 4: SILENCE ON THE MIDDLE
  компетенции 10-70 перцентиль помечаются "не в фокусе",
  рекомендаций по умолчанию не генерируется
```

## Принципы выбора рекомендаций

### Триггер-логика

| Ситуация в профиле | Что делает движок |
|---|---|
| Есть деструктор (<10) | Единственная активная ветка — «тушение» через обратную связь и микро-практики |
| Нет деструкторов, 70–90 перцентиль | Кандидат в «точку роста» |
| Нет деструкторов, ≥90 | Суперсила, предлагаются спутники для устойчивости/расширения |
| 10–70 без статуса деструктора | Осознанно не рекомендуется развитие |

### Фильтр выбора точки роста

Кандидат должен пройти все три фильтра:
1. **Сила** — перцентиль ≥ 70 (данные 360°)
2. **Интерес** — пользователь подтверждает желание вкладываться
3. **Потребность** — HR/оргконтекст подтверждает релевантность

### Механика рекомендации: компетенции-спутники

Для выбранной точки роста система берёт 7–8 спутников (см. `03-companion-matrix.md`), сортирует по собственному перцентилю пользователя и рекомендует топ-1–2 — те, что уже относительно сильны (быстрый эффект).

### Формат рекомендации

Не курс, а поведенческий тренажёр, привязанный к «трудному диалогу»:
*Ситуация-триггер → Типичная (слабая) реакция → Целевая (выдающаяся) реакция → Скрипт → Рефлексия после*.

### Анти-принципы (чего движок не делает)

- Не выдаёт усреднённый универсальный план развития «под роль»
- Не предлагает развитие компетенций в зоне 10–70 перцентиля как приоритет
- Не игнорирует деструктор ради более приятной рекомендации по суперсиле
- Не опирается только на самооценку при определении точки роста
