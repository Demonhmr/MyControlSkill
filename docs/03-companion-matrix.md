# Матрица компетенций-спутников (19 × 7)

Логика — не «усиливай похожее», а **добавляй компетенцию из другого кластера**, которая превращает силу в восприятие (пример из статьи: экспертиза + построение отношений). Рабочая гипотеза-каркас для MVP; в проде матрица должна калиброваться по факту — какие пары действительно поднимают перцентиль базовой компетенции с 75 до 90+ в реальной нормативной базе.

**Легенда кодов:** `INT`-цельность/честность · `EXP`-экспертиза · `PSA`-решение проблем · `INN`-инновации · `LRN`-скорость обучения · `RES`-ориентация на результат · `GOL`-напряжённые цели · `INI`-инициатива · `DEC`-принятие решений · `RSK`-принятие риска · `COM`-коммуникация · `INS`-вдохновение/мотивация · `REL`-построение отношений · `DEV`-развитие других · `COL`-командная работа · `DIV`-ценность разнообразия · `VIS`-стратегическое видение · `CHG`-поддержка изменений · `CUS`-фокус на клиенте

| # | Целевая компетенция | Спутники (→75→90 перц.) | Логика связки |
|---|---|---|---|
| 1 | **INT** — цельность/честность | DEC, COM, VIS, DEV, COL, RES, CHG | Честность без решительности и коммуникации пассивна; в связке с видением читается как «принципиальный лидер» |
| 2 | **EXP** — экспертиза | REL, COM, DEV, COL, INN, VIS, INI | Чистая экспертиза = «умный, но далёкий»; отношения и коммуникация превращают её во влияние |
| 3 | **PSA** — решение проблем/анализ | DEC, INN, RES, COM, VIS, RSK, COL | Анализ без решительности и риска остаётся «умным наблюдателем» |
| 4 | **INN** — инновации | RSK, CHG, VIS, PSA, COM, INS, COL | Идеи без риска и продвижения изменений не долетают до реализации |
| 5 | **LRN** — скорость обучения | INN, DEV, COL, COM, CHG, PSA, INT | Обучаемость незаметна, пока не транслируется через инновации/развитие других |
| 6 | **RES** — ориентация на результат | DEC, INI, COM, INS, COL, VIS, DEV | «Результатник» без вдохновения и коммуникации воспринимается как жёсткий |
| 7 | **GOL** — напряжённые цели | VIS, INS, COM, RSK, DEC, COL, CHG | Амбициозные цели без вдохновения — давление, а не лидерство |
| 8 | **INI** — инициатива | RSK, DEC, COM, VIS, INS, COL, CHG | Инициатива без риска и решительности гаснет на этапе идеи |
| 9 | **DEC** — принятие решений | INT, COM, PSA, RES, VIS, COL, RSK | Решения без честности и коммуникации порождают недоверие |
| 10 | **RSK** — принятие риска | DEC, INN, VIS, COM, INT, COL, CHG | Риск без честности/видения выглядит хаотичным |
| 11 | **COM** — коммуникация | VIS, INS, INT, DEC, DEV, COL, CHG | Коммуникация без содержания — «красиво говорит ни о чём» |
| 12 | **INS** — вдохновение/мотивация | VIS, COM, DEV, INT, GOL, COL, CHG | Вдохновение без честности и цели воспринимается как манипуляция |
| 13 | **REL** — построение отношений | COM, COL, DIV, DEV, EXP, INT, INS | Отношения без экспертизы/честности — «приятный человек», не лидер |
| 14 | **DEV** — развитие других | COM, REL, INS, COL, DIV, LRN, INT | Развитие других без отношений и коммуникации формально |
| 15 | **COL** — командная работа | COM, DIV, REL, DEV, INT, INS, CHG | Командность без разнообразия/честности — конформизм |
| 16 | **DIV** — ценность разнообразия | COL, COM, REL, DEV, INT, INS, CUS | Декларация разнообразия без командной работы — формальность |
| 17 | **VIS** — стратегическое видение | COM, INS, CHG, RSK, DEC, GOL, INN | Видение без коммуникации остаётся «в голове у руководителя» |
| 18 | **CHG** — поддержка изменений | COM, VIS, INS, RSK, COL, INT, INI | Изменения без честности и видения — «спускание директив» |
| 19 | **CUS** — фокус на клиенте/среде | COL, COM, INN, REL, DIV, VIS, DEC | Клиентоориентированность без инноваций — «слушаем, но не меняем» |

**Использование движком:** для выбранной точки роста берутся эти 7 кандидатов, сортируются по собственному перцентилю пользователя (убыв.), рекомендуются топ-1–2 — те, что уже относительно сильны (быстрый эффект, «усиление, а не старт с нуля»).

Соответствует коду: `app/src/data/index.js` → `COMPANIONS`.
