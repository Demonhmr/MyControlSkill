# Спецификация экранов

Общая последовательность:
`Опрос 360° → Деструкторы → Карта силы → Точка роста → План развития → Тренажёр → Пульс-трекер → (для HR) Дашборд команды`

## 1. Опрос 360°

Форма для одного респондента: мета-блок (роль, срок наблюдения) → 19 компетенций (по кластерам, 2 пункта каждая) → 10 деструкторов (2 пункта каждый) → 2 открытых вопроса → отправка. Счётчик собранных внешних анкет относительно порога `MIN_RESPONDENTS = 3`.

## 2. Деструкторы (приоритетный экран)

Список 10 деструкторов, отсортирован от самого критичного. Деструкторы < 10 перцентиля помечены «Критично» и разворачивают блок действий: открыть тренажёр по этой зоне / отметить как проработанное. Пока хотя бы один критический деструктор активен — экраны «Точка роста» и «План развития» заблокированы (доступны только для просмотра на «Карте силы»).

## 3. Карта силы

19 компетенций, sequential-цвет по перцентилю. Зона 10–70 визуально приглушена и подписана «не в фокусе — усиление здесь не влияет на восприятие лидерства». Компетенции ≥90 отмечены как «Суперсила». Отдельный блок «Слепые зоны» — компетенции с большим расхождением self vs 360.

## 4. Точка роста (интерактивный выбор)

Кандидаты — компетенции ≥70 перцентиль. На каждой карточке: чекбокс «интерес», индикатор совпадения с выбранными «вызовами команды» (потребность). Кнопка «Выбрать точкой роста» активна только когда все три фильтра (сила×интерес×потребность) выполнены.

## 5. План развития

Показывает выбранную точку роста и топ-2–3 компетенции-спутника (из матрицы, см. `03-companion-matrix.md`), отсортированные по собственному перцентилю пользователя — с обоснованием связки.

## 6. Тренажёр «Трудный диалог»

Карточка: ситуация-триггер → типичная (слабая) реакция → целевая (выдающаяся) реакция → скрипт фразы. Форма рефлексии после разговора с сохранением записей по конкретной компетенции/деструктору.

## 7. Пульс-трекер

Линейный график перцентиля во времени для выбранной точки роста (и деструктора, если он был в работе), с пороговыми линиями 10/70/90 и hover-тултипами. Таблица-дубль для доступности.

## 8. HR-дашборд

Тепловая карта деструкторов по руководителям (риск-приоритизация) + карта суперсил команды (для формирования пар наставничества, распределения проектов). В прототипе — независимый мок на 8 руководителей; в реальном продукте — агрегация профилей `computeProfile()` по каждому руководителю.

## Общие UI-принципы (см. `dataviz`-гайд, применённый в реализации)

- Sequential-цвет (один тон, light→dark) для перцентиля — никогда «радуга»
- Категориальные цвета только для идентичности (кластеры компетенций), фиксированный порядок
- Статус-цвета (критично/норма) — всегда с иконкой и подписью, не только цветом
- Каждый график имеет табличный дубль («Показать как таблицу»)
- Тонкие линии, hairline-сетка, hover-тултипы на каждом графике
